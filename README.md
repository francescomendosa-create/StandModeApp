# StandMode

Web app landscape a tutto schermo, stile standby iPhone: orologio analogico, data grande e calendario del mese.

## Avvio

Apri `index.html` da un server locale (HTTPS o localhost consigliati per PWA / fullscreen).

Esempio:

```bash
npx --yes serve .
```

Sul telefono: aggiungi alla Home, ruota in landscape. Doppio tap = fullscreen.
